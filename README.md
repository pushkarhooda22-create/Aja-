## 🚀 How to Use

1. **Download or Clone** this repository
2. **Edit Content** in `index.html`:
   - Update restaurant name and location
   - Modify contact information
   - Customize menu items and descriptions
3. **Customize Colors** in `styles.css`:
   ```css
   :root {
       --primary-color: #1a1a1a;        /* Main dark color */
       --secondary-color: #d4a574;      /* Gold accent */
       --accent-color: #c41e3a;         /* Burgundy/Red */
   }
   ```
4. **Add Images** - Replace placeholder areas with your own photos
5. **Deploy** - Upload to any web hosting or GitHub Pages
